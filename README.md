ABCU Advising Program

this repo has my project one run time and memory analysis and my project two code. the code prints the computer science courses in alphanumeric order.

What was the problem you were solving in the projects for this course?

the advisors needed a program that loads a file of courses and prints them all in order, and also prints the title and prereqs for one course. i had to figure out what data structure was the best for it.

How did you approach the problem? Consider why data structures are important to understand.

i wrote pseudocode for a vector, hash table, and a binary search tree and looked at how fast each one is. the vector got to be sorted every time, the hash table aint in order, and the tree is already in order and finds a course fast so i went with the tree. it showed me that what data structure you pick matters alot for how good the program works.

How did you overcome any roadblocks you encountered while going through the activities or project?

my tree pseudocode was for bids so i had to redo it for courses. the csv file also had blank spots and weird extra characters that messed up the courses so i cleaned up each line before using it. i also tried a wrong file name and bad menu choices to make sure it gives an error and dont crash.

How has your work on this project expanded your approach to designing software and developing programs?

before i would just start coding right away. now i plan it out with pseudocode first and think about how fast its gonna be. it made the coding way easier.

How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

i split the program into small functions that each do one thing and i use names that make sense. its easier to read and i can change stuff later without breaking everything.
